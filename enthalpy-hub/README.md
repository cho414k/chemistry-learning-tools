# CHEM LAB — 화학 수업 허브

## 로컬 일기장
허브의 **하루의 조각** 카드 또는 `/diary/`에서 실행합니다. 날짜·기분·제목·본문 작성, 제목/본문 검색, 월별 필터, 수정·삭제를 제공합니다. 저장 버튼을 눌러 저장하며, 저장 전 이동 시 확인합니다.

Node.js 22.13 이상(권장: 현재 설치된 24)에서 `node server.mjs`로 실행하세요. 일기장은 로컬 서버가 필요합니다. 데이터베이스는 **이 README와 같은 폴더의 `local-data/diary.sqlite`**에 자동 생성됩니다. 브라우저를 닫거나 서버를 재시작해도 기록은 유지됩니다. 인터넷 연결이나 추가 패키지 설치는 필요 없습니다.

백업: 서버를 종료한 뒤 `local-data` 폴더를 안전한 위치로 복사하세요. 복원: 서버 종료 후 백업 폴더를 원래 위치로 돌려놓으세요. 일기는 암호화되지 않은 개인용 SQLite 파일이므로 이 PC 계정/폴더 접근 권한을 가진 사람은 읽을 수 있습니다. DB 폴더는 Git에서 제외되며 HTTP 정적 파일로 제공되지 않습니다. 서버는 127.0.0.1에서만 접속을 받습니다. 공개 호스팅은 하지 않습니다.

일기 검증: `node --test tests/diary.test.mjs` (실제 임시 SQLite 파일 생성, 재개방 후 유지, 한글·줄바꿈, 수정·삭제, 잘못된 날짜/빈 제목 검증).

HTML/CSS/JavaScript로 만든 모바일 우선 허브와 엔탈피 개념 게임입니다. 외부 패키지·폰트·API 없이 실행합니다. 기존 chemistry-portal은 수정하지 않았습니다.

## 실행
이 폴더에서 `node server.mjs` 후 http://127.0.0.1:4180 을 여세요. Node.js가 필요하며 패키지 설치는 필요 없습니다. npm이 있는 환경은 `npm start`도 가능합니다. 종료: Ctrl+C. 다른 포트는 PowerShell에서 `$env:PORT=4181` 설정 후 실행합니다.

## 기능
- 허브 → 소개 → 다섯 문항 → 즉시 판정·해설 → 점수·전체 복습 → 재도전
- 발열·흡열, ΔH 부호, 계·주위, 상대 엔탈피 SVG
- 선택 후 제출, 중복 채점 차단, 진행 중 복귀 확인
- 이름·로그인·기록 저장·순위·시간제한 없음. 페이지 메모리만 사용하며 새로고침/이탈 시 소실
- 움직임 줄이기 대응, 키보드 선택, 판정 알림, 그림 텍스트 대안

## 확장
`data.js`의 programs 배열에 id/title/description/topic/href를 추가하고 `app.js`의 경로 허용·route 처리를 새 프로그램에 연결하세요. 등록 정보와 게임 구현은 별도이며, 미구현 경로는 준비 중으로 표시합니다. 엔탈피 문항은 questions에서 관리합니다. 정답 ID는 보기 ID와 일치해야 합니다. 현재 게임은 5문항 전용입니다.

## 디자인
제공된 DESIGN.md의 검은 배경·보라색 버튼·큰 제목·여백·입자 효과를 반영했습니다. 폰트 파일 미제공으로 외부 요청 없는 한국어 시스템 대체 글꼴을 사용합니다. 보기의 선택·키보드 식별을 위해 윤곽선을 추가하고 본문 굵기를 가독성에 맞춰 조정했습니다.

## 검증
`node --check app.js` — JavaScript 구문 검사. data.js/engine.js/server.mjs에도 적용합니다.
`node --test tests/engine.test.mjs` — 데이터 오류, 미선택 응답, 중복 제출, 0/2/5점, 그림의 부호 일치 검증. npm이 있으면 `npm run check`, `npm test`도 가능합니다.

검증 결과: 구문 검사와 자동 테스트 5개 통과. 로컬 HTTP 200. 내장 브라우저에서 허브→소개→5문항→4/5점 결과·전체 복습, 미선택 안내, 오답 해설, 진행 중 복귀 취소, 재도전의 답안 초기화, 새로고침 후 소개 복귀를 확인했습니다. 애플리케이션 소스에서 저장 API·외부 URL·fetch 호출을 사용하지 않음을 확인했습니다. 실제 휴대폰·학교망 및 200% 확대·대비 수치의 전체 검증은 미실시입니다.

실제 학교망·휴대폰 하드웨어·호스팅 정책은 배포 전 별도 확인해야 합니다. 과학 문항은 수업 적용 전 교사 검토가 필요합니다. 브라우저에서 정답 데이터를 읽을 수 있으므로 연습용입니다. 배포는 실행하지 않았습니다.

## PDF 글자 수 도구 (추가)
허브의 PDF 카드에서 실행하거나 `/pdf-counter/`로 접속합니다. 공백 포함/제외 글자 수, 페이지별 집계, 추출 텍스트 확인, 초기화/취소를 제공합니다. 최대 50 MB, 한 파일씩 처리합니다. 줄바꿈 제외, Unicode NFC 정규화 후 grapheme 단위 집계입니다. PDF 텍스트 항목 사이에 임의의 공백을 추가하지 않습니다.

PDF.js 5.4.624 (Apache-2.0, vendor/LICENSE)를 로컬에 포함했습니다. Uint8Array.toHex 미지원 브라우저용 호환 코드를 두 배포 파일 앞에 추가했습니다. CMap/표준 글꼴도 로컬 포함합니다. PDF는 arrayBuffer로 읽어 브라우저 워커에서 해석하고 결과는 페이지 메모리에만 보관합니다. 서버는 GET/HEAD 정적 파일 제공만 허용하며 업로드 API, 외부 CDN, 분석 도구, 결과 저장 API가 없습니다. CSP로 외부 연결과 폼 전송을 제한합니다. PDF의 스크립트를 실행하지 않습니다.

스캔 PDF의 OCR은 지원하지 않으며 암호 PDF는 해제한 사본이 필요합니다. PDF 글꼴 매핑이나 배치에 따라 텍스트·띄어쓰기·순서가 원문과 다를 수 있습니다. 최신 Chrome/Edge 권장. 인터넷 연결 없이 로컬 서버로 사용할 수 있습니다.

검증: 기존 게임 5개 및 PDF 집계/실제 PDF 추출 3개 테스트 통과, 주요 JS 구문 검사, 로컬 HTTP 200 확인. 내장 브라우저에서 루프백 접속이 ERR_BLOCKED_BY_CLIENT로 차단되어 화면·파일 선택의 브라우저 통합 검증은 미완료입니다. 공개 배포는 하지 않았습니다.

# Chemistry Club

DESIGN.md의 검정 캔버스, 보라색 액션, 큰 타이포그래피, 삼각형 입자를 반영한 한국어 화학 게임 포털입니다. 호스팅 등록과 공개 배포는 하지 않았습니다.

## 로컬 실행

Node.js 18 이상에서 이 폴더를 터미널로 열고 실행하세요. 외부 패키지 설치는 필요 없습니다.

```powershell
node server.cjs
```

브라우저에서 http://127.0.0.1:4173 을 여세요. 서버는 로컬 루프백에만 바인딩합니다. 종료는 Ctrl+C입니다. 포트 4173을 사용 중이라면 해당 서버를 종료한 후 실행하세요.

## 기능

- 5문제 원소 퀴즈: 첫 답변을 채점
- 3문제 반응식: 최소 정수 계수 확인, 재시도 가능
- 3문제 분자 조립: 원자 선택과 초기화, 재시도 가능
- 난이도 필터, 최고 기록과 완료 횟수 브라우저 저장
- 반응형 레이아웃, 키보드 조작, Escape로 게임 닫기, 동작 줄이기 설정 반영

Google Fonts에서 Inter와 Noto Sans KR을 불러옵니다. 인터넷이 없으면 시스템 폰트로 동작하며 게임 자체는 외부 서비스 없이 실행됩니다. PPNeueMontreal 폰트 파일은 제공되지 않아 대체 폰트를 사용했습니다. 기록은 기기나 브라우저 간 공유되지 않습니다.

## 확인

```powershell
node --check dist/app.js
node --check server.cjs
```

게임별 완료 화면, 기록 저장 후 새로고침, 난이도 필터, 모바일 화면을 확인하세요.
